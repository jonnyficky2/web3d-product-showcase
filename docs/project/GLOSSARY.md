# Glossary

- **WebGL:** Browser graphics API used by the current Three.js renderer.
- **Three.js:** JavaScript 3D library loaded at runtime from jsDelivr.
- **Procedural geometry:** Meshes constructed from Three.js primitives instead of local model files.
- **PBR:** Physically based material workflow; current code uses `MeshPhysicalMaterial` for selected surfaces.
- **DPR:** Device pixel ratio used to size the renderer buffer.
- **Draw call:** A GPU submission for rendering an object/material batch.
- **LOD:** Level of detail; not implemented in the current source.
- **Fallback:** User-facing state shown when the main rendering path cannot initialize.
