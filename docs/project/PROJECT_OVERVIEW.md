# Project Overview

Forma is a single-page interactive product showcase. It renders three procedural products in WebGL and overlays product information and controls in HTML.

## Verified capabilities

- Three.js r169 loaded through a browser Import Map.
- Speaker, headphones, and watch procedural meshes.
- Orbit, zoom, pan, damping, product switching, color switching, and idle rotation.
- Responsive CSS layout with a mailto CTA.

## Explicit non-capabilities

- No backend, database, authentication, payment processing, CMS, asset upload, analytics, or local model files were found.
- No automated test suite or build pipeline was found.

## Main files

- `index.html`: complete application.
- `README.md`: setup and legacy project description.
- `docs/`: product, architecture, flow, and operational documentation.
