# Design System

## Visual direction

Dark studio background, cool neutral text, translucent control panel, rounded controls, and product-focused 3D lighting.

- Background: `#090d14`, `#0b1018`, `#111821`.

- Product palette: Sand `#c5a982`, Slate `#647f9e`, Rose `#a56768`.
