# UX Flows

## Explore

Load page → default speaker appears → user drags/zooms/pans → idle rotation pauses and later resumes.

## Switch product

Click product tab → visibility changes → copy/specs/CTA update → color resets to Sand → rotation cooldown begins.

## Contact

Choose product/color → click CTA → browser opens the default mail client.

## Failure flow

Currently undefined. A future implementation must cover WebGL unavailable, CDN unavailable, and first-render failure.
