# UI Specifications

## Regions

- Topbar: brand, navigation anchors, edition label.
- Status: interactive preview indicator.
- Product switcher: three pressed-state buttons.
- Product copy: category, title, description, specs.
- Controls panel: swatches, CTA, interaction hint.

## Responsive behavior

Below `680px`, navigation is hidden, switcher and copy move inward, and the control panel spans the bottom of the viewport.

## Known gaps

Support has no target section. Loading, WebGL failure, and keyboard-specific 3D instructions are not implemented.
