# Test Plan

## Manual baseline

Run a local HTTP server, open the root page, and verify:

1. Speaker loads.
2. Tabs switch exactly one visible product.
3. Swatches update the active product.
4. Orbit, zoom, and pan respect limits.
5. Resize and orientation changes preserve aspect ratio.
6. CTA subject matches the active product.

## Required future matrix

Desktop Chrome/Firefox/Safari/Edge, iOS Safari, Android Chrome, reduced-motion enabled, WebGL disabled, offline/CDN blocked, and throttled low-end CPU/GPU.
