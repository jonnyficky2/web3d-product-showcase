# AI Workflow

1. Read the index, project state, and task board.
2. Inspect the affected source and verify assumptions.
3. Define the smallest change and expected verification.
4. Implement without unrelated rewrites.
5. Run available checks and record limitations.
6. Update requirements, task status, project state, and relevant audit documents.
7. Add an ADR for significant architecture decisions.
8. Report changed files, verification results, and remaining uncertainty.
