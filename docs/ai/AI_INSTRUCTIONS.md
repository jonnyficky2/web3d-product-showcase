# AI Coding Instructions

## Read first

1. `DOCUMENTATION_INDEX.md`
2. `docs/project/PROJECT_STATE.md`
3. `docs/project/TASK_BOARD.md`
4. The relevant source and feature documents

## Rules

- Do not assume frameworks, APIs, databases, or features that are absent.
- Preserve the zero-build architecture unless an ADR approves a change.
- Do not modify or delete existing functionality without explicit scope.
- Keep application changes separate from documentation changes.
- Use `PENDING` or `UNKNOWN` for unverified claims.
- Run browser/static verification proportional to risk.
- Update task status, requirements, state, and audit documents after significant work.
- Never include secrets in commits or documentation.
