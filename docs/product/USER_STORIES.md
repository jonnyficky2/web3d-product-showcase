# User Stories

- `US-001`: As a visitor, I want to rotate a product so I can inspect it from multiple angles.
- `US-002`: As a visitor, I want to switch products so I can compare the collection.
- `US-003`: As a visitor, I want to change color so I can preview a preferred variant.
- `US-004`: As a visitor, I want to read key specifications before contacting the seller.
- `US-005`: As a visitor, I want a usable experience on touch devices.
- `US-006`: As a developer, I want documented runtime limitations so I can safely extend the prototype.
